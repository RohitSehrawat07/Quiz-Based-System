# Happy Kids Quiz Website

A responsive, beginner-friendly quiz website for Nursery–Class 5 students.

## Run it
1. Install Node.js, then run `npm install` in the project folder.
2. Run `npm start`.
3. Open `http://localhost:3000` in your browser.

The quiz also works when opening `index.html` directly, but creating and joining
online rooms requires the server to be running with `npm start`.

## Included
- Maths, English and Science quizzes (10 questions per subject)
- Student name and class selection
- Instant answer feedback and explanations
- Score tracking and final result
- Mobile-friendly layout
- No login or database required

## Customize
Open `index.html` in a code editor. Questions are inside the `questionBank` object in the JavaScript section.
